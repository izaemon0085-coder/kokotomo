# こことも（β版）

旅や、障害のある人の移動を助けるアプリです。推し活SNS「ともはね」とつながります。

| 機能 | URL | 中身 |
| --- | --- | --- |
| おたすけカード | `/card.html` | 手伝ってほしいことを選んで、駅や会場で画面いっぱいの大きな文字で見せる。読み上げ・筆談つき。**中身はスマホの中（localStorage）だけに保存し、サーバーには送らない**。ネットがなくても使える |
| 会場のバリアフリーメモ | `/venues.html` | エレベーター・スロープ／多目的トイレ／車いす席・入り口／休める場所／混む時間・場所／そのほか。行った人が書き足す。書いた日を必ず出し、180日より古いメモは「古いかもしれません」と知らせる |

## 起動

Node.js 20 以上が必要です。外部パッケージは使っていません。

```sh
npm start        # http://localhost:3100
npm run dev      # ファイル変更で自動再起動
npm test         # API テスト
```

会場メモは `data/venues.json` に保存されます（`data/` は git に入りません）。
環境変数 `PORT` でポートを、`PUBLIC_URL` でほかのアプリに返すリンクの先頭（例：`https://kokotomo.example.jp`）を変えられます。

## ともはねとのつながり

- ともはねの「わたしの推し」に次のライブ会場を登録すると、その会場のバリアフリーメモの要点が出る
- ともはねに渡すのは **会場メモ（もともと公開の情報）だけ**。おたすけカードや位置情報は渡さない
- ログインは別々。つなぐのは会場の名前だけ

## 書きこみの安全

- 会場のことだけを書く場所。電話番号・郵便番号・メールアドレスのようなもの、トゲのある言葉は書けない
- β版は名前なしで書ける。荒らし対策として、あとで人の確認を入れる
- メモはみんなで書いたもの。出かける前に、会場や駅にも確かめるよう画面で案内している

## API

| メソッド | パス | 説明 |
| --- | --- | --- |
| GET | `/api/topics` | メモの項目 |
| GET | `/api/venues?q=〇〇` | 会場を名前でさがす（全角・半角、空白、「・」のちがいは無視） |
| POST | `/api/venues` | 会場を足す `{name}`（同じ名前があれば、それを返す） |
| GET | `/api/venues/:id` | 会場のメモ（書いた日つき） |
| POST | `/api/venues/:id/notes` | メモを書き足す `{topic, text}` |
| GET | `/api/link/venue?name=〇〇` | ほかのアプリ用。会場名にいちばん近い会場の、項目ごとの最新のメモ |

## まだ作っていないもの

- 遠征のしおり（休けいやエレベーターのある道、介助をお願いする連絡文の下書き）
- 同行者との連絡（ローカル回線）
- 書きこみの確認（人の目）と通報
- 知らない人どうしで同行する機能は、安全のため β版では作らない
